Download the ZIP above (about 75 MiB), extract it to a writable folder, then run `NN VLA V1.0.11.exe` inside the extracted `NN-VLA-v1.0.11-preview` folder.

**Development preview:** The native VLA service and driver are not bundled. This build cannot set up tunnelling on a fresh PC. Hosting or joining requires an already installed compatible service. Automatic VLA removal is disabled, and a two-PC test is still outstanding. The EXE is unsigned, so Windows may show a warning.

The preview includes the compact Host and Join UI, room keys, password and block controls, user list, network diagnostics, and profile editing. See [release notes](RELEASE_NOTES.md) for details.
